# Virtual Buttons

A native Android app that replaces damaged or unresponsive physical volume buttons with fast, reliable software controls that work from any app.

## Features

- **Floating Button** - Draggable overlay, swipe up/down to change volume, double-tap to mute, long-press to hide
- **Edge Gestures** - Swipe on left/right screen edges to adjust volume  
- **Quick Settings Tile** - One tap to toggle overlay
- **Notification Controls** - Up, down, mute, show, stop actions
- **Shake to Mute** - Optional shake gesture
- **Auto Night Profile** - Scheduled volume lowering

## Settings

In the app you can configure:
- Gesture mode: Swipe, Double-tap, or Both
- Gesture sensitivity
- Button size and opacity
- Edge strips enable/width
- Volume step
- Start on boot
- Hide notification
